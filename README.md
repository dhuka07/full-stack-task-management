# 📝 Task Management App

A simple, responsive, and aesthetic task manager built with **Node.js (Express)** and **vanilla HTML/CSS/JavaScript**. Users can add, toggle, and delete tasks with optimistic UI updates and task filtering. Includes JWT-based user authentication and mobile-first design.

---

## 🚀 Features

- ✅ Add tasks with title and description  
- 🔁 Toggle task completion status  
- ❌ Delete tasks  
- 📋 Filter tasks by status (All / Completed / Pending)  
- ⚡ Optimistic UI updates (instant toggle feedback with rollback on failure)  
- 🔐 JWT-based login for secure task ownership  
- 📱 Fully responsive and mobile-friendly design  
- 🎨 Aesthetic UI with gradient backgrounds and button styles
