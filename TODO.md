# TODO 🚧

Build a simple task management application with a Node.js backend and a front-end interface.
Description:
Create a full-stack application where users can:
View a list of tasks.
Add a new task (title and description required).
Mark a task as completed.
Delete a task.
Backend Requirements:
Set up an Express server with RESTful endpoints:
+GET /tasks: Retrieve all tasks.
+POST /tasks: Create a new task (validate title and description).
+PUT /tasks/:id: Update task status (completed or not).
+DELETE /tasks/:id: Delete a task.
